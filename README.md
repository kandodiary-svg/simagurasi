# ほしなみ島ぐらし

瀬戸内の島を舞台にした、島ぐらし3Dゲーム（Three.js）。

- 遊ぶ: GitHub Pages で公開した `index.html` を開く
- 中身: `index.html`（ゲーム本体）、`models/`（人・乗り物の3Dモデル .glb）、`sfx/`（効果音・BGM）
- ソース: `source/src/`（`order.txt` の順に結合）。`source/` で `python3 build.py` → 1ファイル版、`python3 build_pages.py ..` → このフォルダ（GitHub Pages 版）を作り直す
- 効果音は CC0（Freesound・Kenney）と効果音ラボの素材
